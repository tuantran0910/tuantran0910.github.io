# Contributing

## Lesson template

Each chapter should contain:
1. Learning objectives and prerequisites.
2. Architecture and end-to-end request/reconciliation flow.
3. Core concepts with clear control-plane/data-plane boundaries.
4. Copyable YAML and shell examples with prerequisites.
5. Production failure modes and troubleshooting.
6. Lab, acceptance criteria and rollback/cleanup steps.
7. Questions, key takeaways and source links.

Mark untested examples as *conceptual*. Do not claim a cluster/GKE resource was verified if no tests were run.

Never add tokens, production credentials, sensitive addresses or private company repositories.
