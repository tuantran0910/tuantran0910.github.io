## Calculate a request-based error budget

Start with a 99.9% SLO, one million eligible requests, and an observed error rate of 0.05%. Change the SLO or error rate to see what happens when the budget is exceeded. The model uses a single request population and one aggregate error rate. Production alerts calculate separate paired-window burn rates.
